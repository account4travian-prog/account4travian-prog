# WriteProject Studio app

A Windows desktop studio built for the A Work of Magic writing project (repo: `WriteProject`, private): manuscript chapters, a full story bible (characters, locations, magic system), plot outlines, and a continuity system, wrapped in a purpose-built app that went through several versions.

**Rules the app enforces**
- The writing guide must be read before any manuscript file is touched.
- AI experiments stay out of the canonical manuscript unless Jordan accepts them.
- An audit script runs after drafts, so changes are checked, not assumed.

**Jordan's role:** the studio exists to keep a long fan-fiction project consistent under heavy AI assistance, the same separation as the chapter pipeline, applied to a single-author book: canonical text is protected, experiments are quarantined, and acceptance is always his.
