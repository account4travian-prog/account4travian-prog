# Media Factory and the Atlas avatar program

**Media Factory** is an AI image and media pipeline run with Sol (GPT/Codex): versioned asset iterations (one series through v40), brand bibles, and a rule that no asset is done until it passes independent review. Output for the Memory Warden brand: covers, promotional images, social banners and avatars, ad creatives, and short video teasers.

**Atlas avatar program.** A low-poly wizard-cat avatar for my agent Atlas, built through a scripted Blender → GLB pipeline, with a file-polling bridge that round-trips between my PC's avatar app and the agent. A parallel pilot had Sol build a first 3D version from open-source models and textures (gray tabby, amber eyes, crescent staff). The model, build script, adapted texture, and hero render are kept; the asset notes and turntable set are not.

**My role:** art director and acceptance authority. Briefs and verdicts are mine; generation and modeling are agent-executed.
