# Media Factory & the Atlas avatar programme

**Media Factory** — an AI image/media production pipeline run with Sol (GPT/Codex): versioned asset iterations (some series past v20), brand bibles, and a standing rule that an asset is not done until it survives independent review. It produces the visual material for the Memory Warden brand (fiction covers, social assets, experiment art).

**Atlas avatar programme** — Jordan's agent Atlas is being given a persistent visual identity: a wizard-cat avatar built as a low-poly 3D model through a scripted Blender → GLB pipeline, with a file-polling bridge that round-trips between the avatar app on Jordan's PC and the agent. A parallel pilot had Sol build a first 3D version from open-source models and textures (grey tabby, amber eyes, crescent staff); its files are kept with the project.

**Jordan's role:** art director and acceptance authority — briefs and iteration verdicts are his; generation and modelling are agent-executed.
